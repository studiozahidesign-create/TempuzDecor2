REDESIGN AND STANDARDIZE THE TYPOGRAPHY SYSTEM ACROSS THE ENTIRE TEMPUS WEBSITE.

This is a GLOBAL DESIGN SYSTEM task.

Do not redesign the pages, change the layout structure, replace the imagery, or introduce new visual styles. The main objective is to fix the typography so the entire website feels coherent, sophisticated, editorial, architectural, and professionally art-directed.

The current website has a strong visual direction, but the typography is inconsistent. Some headings are too large, some text blocks have excessive line height, weights are poorly distributed, and the relationship between headline, supporting text, labels, navigation and CTAs is not systematic.

Typography must become one of the strongest elements of the design system.

==================================================
1. TYPOGRAPHIC DIRECTION
==================================================

The typography should feel:

• sophisticated
• contemporary
• architectural
• editorial
• restrained
• premium
• quiet
• highly legible
• intentional

Avoid:

• oversized "tech startup" typography
• excessive font-weight contrast
• too many font sizes
• random heading scales
• excessively wide text blocks
• excessive letter spacing
• overly bold typography
• decorative typography
• inconsistent line heights
• typography that visually dominates the products and photography

The visual language should be closer to a premium architecture, furniture, interior design or industrial design brand.

The typography should communicate confidence through proportion and spacing, not through huge type sizes.

==================================================
4. FONT WEIGHTS
==================================================

Use very few weights.

Primary weights:

400 = Regular
500 = Medium

Do not use 600, 700 or 800 unless absolutely necessary.

The visual identity should rely primarily on Regular and Medium.

Headlines should generally use 400.

Body copy should use 400.

Labels and navigation can use 400 or 500.

CTAs can use 400 or 500.

Avoid bold typography throughout the website.

The current visual direction depends on subtle hierarchy rather than heavy weight contrast.

==================================================
5. HEADLINE TREATMENT
==================================================

Headlines should use sentence case.

Do not use unnecessary uppercase headlines.

When a headline contains two conceptual parts, the secondary part can use the existing lighter/secondary text color.

Example:

"Desenhamos o
repouso como
arquitetura."

The typography should make the hierarchy clear without requiring different font sizes for every line.

Another example:

"Conforto para cada
ritmo de viver."

The first conceptual phrase can use the primary text color and the second phrase can use the muted text color.

Do not artificially create this effect with different font weights.

18. COLOR AND TYPOGRAPHIC CONTRAST
==================================================

Maintain the existing restrained Tempus palette.

Primary text:
dark / near-black

Secondary text:
muted gray

Do not introduce new colors just to create hierarchy.

Use opacity or the existing muted color for secondary typographic information.

The lighter typography treatment used in headlines should be subtle.

Do not make secondary words so light that readability is compromised.

==================================================
19. ALIGNMENT
==================================================

Typography must always respect the underlying layout grid.

Text should align consistently with:

• image edges
• product cards
• section containers
• navigation
• content columns
• CTA lines

Avoid arbitrary text positioning.

Whenever text describes an image, product, card or visual element, visually align the text with that element.

This is particularly important throughout the homepage.

==================================================
21. SECTION HEIGHT
==================================================

This is also a global correction.

Do not allow typography to force sections into unnecessarily tall layouts.

The current website frequently creates sections larger than approximately 900px.

Avoid this.

Sections should generally feel compact and intentional.

Use typography to improve density and rhythm instead of creating large empty vertical spaces.

Do not artificially center small amounts of text inside enormous sections.

If a section contains little content, reduce its height.

The visual identity should come from composition, imagery, typography and spacing, not empty viewport-sized sections.

==================================================
23. AUDIT THE EXISTING WEBSITE
==================================================

Before changing anything, review every page currently implemented.

Identify:

• inconsistent font sizes
• inconsistent weights
• inconsistent line heights
• oversized headlines
• undersized supporting text
• excessive letter spacing
• inconsistent margins
• paragraphs that are too wide
• typography that is poorly aligned with images
• duplicate typography styles
• sections that became too tall because of typography
• headings that visually compete with photography

Then consolidate them into the new global system.

Do not preserve bad existing typography just because it currently exists.

==================================================
24. IMPORTANT VISUAL PRINCIPLE
==================================================

The final website should NOT look like a website where every section has a different typography treatment.

It should feel like one carefully designed publication.

A user should be able to move from:

Homepage → Product → About → 3D Blocks → Representatives → Careers → Blog → Article

and immediately recognize the same typographic language.

The typography should feel almost invisible in its consistency.

The design should communicate sophistication through:

PROPORTION
SPACING
ALIGNMENT
WEIGHT
RHYTHM
TYPOGRAPHIC RESTRAINT

not through oversized text.

==================================================
FINAL QUALITY CHECK
==================================================

After implementing the system, review every page at desktop and mobile sizes.

Check:

1. Are all headings using a consistent hierarchy?
2. Are weights consistent?
3. Are line heights visually balanced?
4. Are paragraphs too wide?
5. Are headlines unnecessarily large?
6. Are text blocks aligned with imagery?
7. Are CTAs consistent?
8. Are labels consistent?
9. Are sections unnecessarily tall?
10. Does the entire website feel like one brand?

The final result should feel like a high-end Brazilian furniture and design brand with an editorial, architectural and contemporary character.

Typography should be calm, precise and sophisticated.

Do not over-design it.
Do not add more styles.
Do not make it louder.

Make it more coherent.
