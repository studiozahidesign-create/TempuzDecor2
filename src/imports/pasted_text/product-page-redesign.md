The current product page is functionally complete, but visually it still feels like a collection of independent UI components.

The objective is NOT to redesign the page.

The objective is to elevate the art direction, typography, composition and editorial rhythm to the level of a premium furniture brand.

Use the attached reference ONLY as inspiration for visual composition, hierarchy and editorial rhythm.

Do NOT copy its layout.

The Tempus product page contains different content blocks and must preserve its own information architecture.

--------------------------------------------------
GENERAL ART DIRECTION
--------------------------------------------------

The current page feels too technical.

Typography lacks hierarchy.

Spacing feels arbitrary.

Alignment feels inconsistent.

Sections behave like isolated containers.

The redesign should feel calm, architectural and intentional.

Every section should feel like part of the same visual story.

--------------------------------------------------
TYPOGRAPHY
--------------------------------------------------

Review the entire typography system.

Current typography feels inconsistent.

Improve:

• font scale

• hierarchy

• weight distribution

• spacing between headings and body

• paragraph width

• line-height

Headings should become more elegant and editorial.

Body copy should remain restrained.

Avoid oversized blocks of text.

Allow generous whitespace around typography.

--------------------------------------------------
GRID
--------------------------------------------------

Review the global layout grid.

Many sections currently feel misaligned.

Columns should consistently follow the same grid throughout the page.

Large images, text blocks and technical information should all align to the same invisible architectural structure.

Avoid random offsets.

--------------------------------------------------
SPACING
--------------------------------------------------

Review every section.

Current spacing feels inconsistent.

Some sections are compressed.

Others contain excessive empty space.

Create a clear vertical rhythm.

Spacing should feel deliberate rather than mechanical.

Do not use equal spacing everywhere.

Use spacing to establish hierarchy.

--------------------------------------------------
COMPOSITION
--------------------------------------------------

Think like an editorial designer rather than a UI designer.

Alternate image and text naturally.

Create visual tension between positive and negative space.

Avoid repetitive layouts.

Not every section needs to follow the exact same structure.

Some sections may prioritize imagery.

Others may prioritize typography.

The page should continuously surprise without losing consistency.

--------------------------------------------------
IMAGES
--------------------------------------------------

Photography is the most valuable asset of the brand.

Increase its importance.

Allow images to dominate.

Avoid making photography feel secondary to interface elements.

Large editorial imagery should create rhythm throughout the page.

--------------------------------------------------
TEXT BLOCKS
--------------------------------------------------

Current text blocks are too "boxed".

Allow more breathing room.

Reduce paragraph width.

Increase the relationship between images and copy.

Text should accompany photography—not compete with it.

--------------------------------------------------
TECHNICAL INFORMATION
--------------------------------------------------

Technical information should become quieter.

It should remain highly readable without visually competing with the storytelling sections.

Improve hierarchy using typography and spacing instead of borders or excessive separators.

--------------------------------------------------
SIGNATURE
--------------------------------------------------

Treat Tempus Signature as a premium editorial section.

It should feel aspirational.

Not promotional.

Use elegant composition with strong photography and restrained typography.

--------------------------------------------------
TECHNOLOGY
--------------------------------------------------

Technology should feel like an engineering signature.

Avoid presenting it as a technical specification sheet.

Emphasize:

craftsmanship

innovation

comfort

exclusive engineering

Use icons and typography elegantly.

--------------------------------------------------
MATERIALS
--------------------------------------------------

The material section should become more tactile.

Photography should dominate.

Allow leather, stitching, wood and fabrics to communicate quality before text does.

--------------------------------------------------
DIMENSIONS
--------------------------------------------------

Simplify the dimensions section.

Increase whitespace.

Reduce visual clutter.

Make technical drawings feel elegant.

--------------------------------------------------
RELATED PRODUCTS
--------------------------------------------------

Reduce card density.

Increase image prominence.

Improve spacing.

Create a browsing experience closer to an editorial catalogue than an ecommerce carousel.

--------------------------------------------------
VISUAL RHYTHM
--------------------------------------------------

Throughout the page alternate:

large imagery

↓

small typography

↓

technical content

↓

immersive photography

↓

editorial storytelling

↓

technical information

↓

lifestyle imagery

Avoid repeating the same layout pattern continuously.

--------------------------------------------------
CONSISTENCY
--------------------------------------------------

Maintain:

• Tempus typography

• color palette

• spacing language

• design system

• CTA components

• visual identity

Do not introduce a new design language.

Only elevate the execution.

--------------------------------------------------
REFERENCE
--------------------------------------------------

The attached reference demonstrates:

• strong editorial hierarchy

• refined spacing

• elegant typography

• calm compositions

• premium product presentation

Use these principles as inspiration.

Do NOT reproduce the same layouts.

Respect the unique structure and content requirements of the Tempus website.

--------------------------------------------------
FINAL GOAL
--------------------------------------------------

The finished page should feel closer to an architectural design publication than a traditional ecommerce product page.

Every section should express refinement, craftsmanship, timelessness and premium furniture design.

The user should experience the page as a visual narrative instead of a sequence of interface blocks.
