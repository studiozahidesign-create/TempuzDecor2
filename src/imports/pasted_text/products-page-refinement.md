The "Products Category" page still feels unfinished compared to the rest of the website.

The homepage already establishes a premium architectural language, while this page still feels like a functional product catalog.

The objective is NOT to redesign the website.

The objective is to elevate this page so it matches the same editorial, luxurious and architectural experience already established across the brand.

Every decision should reinforce calm, refinement, whitespace, and premium product presentation.

--------------------------------------------------
01 — HERO SECTION
--------------------------------------------------

Keep the existing hero structure.

The large architectural lifestyle image works well and should remain the visual introduction to the collection.

Only verify that:

- typography follows the homepage hierarchy
- spacing is balanced
- content aligns perfectly with the global grid
- hero height is proportional (avoid oversized viewport heights)

--------------------------------------------------
02 — CATEGORY NAVIGATION
--------------------------------------------------

The horizontal category navigation immediately below the hero requires refinement.

Current problems:

- the section is too tall
- there is excessive empty white space underneath
- the cards feel like placeholders
- the proportions are weak
- the component does not feel premium

Adjust this section so its height is determined by its content instead of a fixed large container.

Reduce unnecessary vertical padding.

The transition between Hero → Categories → Products should feel immediate and natural.

--------------------------------------------------
03 — CATEGORY CARDS
--------------------------------------------------

The category cards should become a curated navigation experience rather than a simple list.

Requirements:

• Use larger and more impactful photography.

• Images should feel editorial.

• Prepare the layout for final professional photography.

• Maintain consistent image proportions.

• Improve spacing between image and category title.

• Add subtle hover interactions.

• Clearly distinguish the active category.

Avoid making them look like generic ecommerce thumbnails.

The overall feeling should resemble an architectural furniture collection.

--------------------------------------------------
04 — REMOVE THE SECOND FILTER BAR
--------------------------------------------------

The secondary filter toolbar should be removed completely.

Currently it displays:

- product count
- collection
- product type
- environment
- technology
- upholstery
- material
- color
- designer
- availability
- sort

This component creates unnecessary complexity.

Most of these controls are not actually filtering meaningful information and only increase visual noise.

Instead:

Reuse the filtering experience that already exists elsewhere in the website.

The project should have one consistent filtering system.

Do not duplicate filters.

Do not create different filtering paradigms.

Consistency is more important than quantity.

--------------------------------------------------
05 — PRODUCT GRID
--------------------------------------------------

The product grid should become the main focus immediately after the category navigation.

Reduce the vertical gap before the first row.

Increase visual prominence.

The user should arrive at products much faster.

Improve the rhythm between rows.

Avoid oversized vertical spacing.

--------------------------------------------------
06 — PRODUCT CARDS
--------------------------------------------------

The cards already have the correct information hierarchy:

- collection
- product name
- subtitle
- CTA

Keep this structure.

Improve only:

• spacing

• alignment

• typography rhythm

• image presentation

Images should occupy more of the available card area.

Avoid large empty margins around products.

Product photography should become the hero of each card.

Cards should feel lighter, cleaner and more premium.

--------------------------------------------------
07 — PRODUCT PHOTOGRAPHY
--------------------------------------------------

Current product images are temporary.

Prepare the layout for final photography.

Photography direction should follow these principles:

- neutral backgrounds
- soft natural daylight
- architectural composition
- minimal styling
- premium furniture editorial aesthetic
- consistent framing
- consistent crop
- identical visual treatment across all products

Images should never feel like ecommerce cutouts.

They should feel like pieces inside a curated design collection.

--------------------------------------------------
08 — PAGE SPACING
--------------------------------------------------

The page currently contains too much unused vertical space.

Review all section spacing.

Reduce excessive:

- top padding
- bottom padding
- section gaps
- empty containers
- fixed heights

Do NOT eliminate whitespace.

Whitespace is an essential part of the Tempus visual identity.

Instead, make whitespace intentional.

The page should breathe without feeling empty.

--------------------------------------------------
09 — PAGINATION
--------------------------------------------------

Keep pagination simple and discreet.

Ensure it sits closer to the product grid.

Avoid large empty areas before the next section.

--------------------------------------------------
10 — RELATED CATEGORIES
--------------------------------------------------

The "Other ways to live comfort" section is conceptually good.

Refine it so it feels like a continuation of the browsing experience.

Improve:

- image proportions
- spacing
- alignment
- hover behavior

Maintain the editorial feeling.

--------------------------------------------------
11 — CONSISTENCY
--------------------------------------------------

Reuse existing design tokens whenever possible.

Reuse:

- typography scale
- spacing system
- CTA component
- hover animations
- grid
- border treatments
- transitions

Avoid introducing new visual languages.

Everything should feel like part of the same design system.

--------------------------------------------------
12 — DESIGN PRINCIPLES
--------------------------------------------------

Every visual decision should reinforce these ideas:

Architectural.

Quiet.

Timeless.

Minimal.

Premium.

Editorial.

Sophisticated.

Intentional.

The page should never feel like a marketplace.

It should feel like browsing a curated furniture collection from a high-end design brand.

--------------------------------------------------
13 — FINAL GOAL
--------------------------------------------------

After the redesign, the browsing flow should feel like this:

Hero

↓

Category Navigation

↓

Product Grid

↓

Pagination

↓

Related Collections

↓

Footer

Every transition should feel fluid.

The user should always feel guided through the collection instead of navigating a traditional ecommerce catalog.

The final result should visually align with brands such as Minotti, Poliform, B&B Italia, Living Divani and Molteni&C, while preserving the unique visual identity and design language of Tempus.
